# Armor Stand Editor (ASE) для Minecraft 1.21.11

Полностью готовый datapack + опциональный resource pack для Paper/Vanilla 1.21.11. Проект добавляет удобный редактор стойки для брони: позы, свойства, экипировка, перемещение и “модельки” через display-entities.

## Кратко о возможностях
- Выбор стойки лучом (raycast) и привязка к администратору.
- GUI-меню через чат и `/trigger` (без опки и без `run_command`).
- Toggles: arms, baseplate, small, invisible, marker, gravity, name_visible, glow.
- Редактор поз: части тела + оси + шаг (1/5/15°) + 8 пресетов.
- Move/Rotate: шаги 0.01–0.25, повороты 1/5/15°, snap 0.25.
- Экипировка из слотов игрока (helmet/chest/legs/boots/mainhand/offhand), очистка.
- Attach Models: `item_display` как пассажиры стойки + смещение/поворот/масштаб.
- Copy/Paste стойки + 5 пресетов.
- Экспорт NBT-команды для восстановления стойки.

## Требования
- Minecraft Java **1.21.11**
- Data Pack format **94.1**, Resource Pack format **75.0**

## Безопасность
- Доступ запрещён всем по умолчанию.
- Дайте доступ: `tag <player> add ase.admin`
- Все обработчики проверяют тег `ase.admin`.

## Как использовать
1. `tag <player> add ase.admin`
2. `/function ase:give` — получить ASE Wand.
3. Посмотрите на стойку (до 6 блоков) и используйте wand.
4. Откройте меню: `/trigger ase.menu`

## Команды/функции
- `/function ase:give` — выдать ASE Wand (только `ase.admin`).
- `/function ase:doctor` — диагностика загрузки datapack.

## Проверки/валидаторы
Запустите локально:
- `python tools/validate_json.py`
- `python tools/validate_calls.py`
- `python tools/build.py`

## Если не получается скачать ZIP из репозитория
В некоторых средах бинарные файлы не отображаются/не скачиваются. В этом случае
запустите в корне проекта:
- `python generate_and_zip.py`
Скрипт создаст `ArmorStandEditor_DP_1.21.11.zip` и `ArmorStandEditor_RP_1.21.11.zip` локально.

## Заметка про бинарные файлы в репозитории
Чтобы избежать ошибок загрузки (например, в некоторых веб-интерфейсах),
PNG-текстуры не хранятся в репозитории. При сборке они создаются автоматически:
- `python tools/generate_textures.py` (только текстуры)
- `python tools/build.py` или `python generate_and_zip.py` (полная сборка)

## Что такое display-модели (display entities)
Display entities (`item_display`, `text_display`, `block_display`) — это сущности, которые отображают предмет/текст/блок как отдельный “объект” в мире. Они хорошо подходят для создания статуй и декоративных объектов, потому что позволяют задавать трансформации (смещение, поворот, масштаб) без сложных трюков с блоками.

## Сравнение
- **Display-модели**: гибкие, не требуют ресурспака для базовых предметов, легко смещаются и масштабируются.
- **Resource Pack модели**: дают настоящие кастомные 3D-модели, но требуют установки RP на клиент.
- **Поза стойки**: быстро, но ограничена формой самой стойки и её экипировкой.

## Ограничения
- Datapack не может менять клиентские ассеты без ресурспака.
- Для “настоящих” кастомных 3D-моделей нужен Resource Pack на клиенте.
- Изменение трансформаций display-entities не является бесконечно точным и работает в разумных пределах.
